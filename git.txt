Hacer merge

#1 git checkout main (para cambiarnos a la rama principal si estamos en una distinta)
#2 git pull (por si trae cambios recientes)
#3 git merge NombreRamaNueva (para hacer el merge con la rama nueva desde la rama main)
#4 git push (para empujar todos los cambios al repo)
